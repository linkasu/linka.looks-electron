# LINKa.смотри 4.0.0

Windows x64: Windows 10 22H2 и Windows 11. Установщик **без цифровой подписи**;
Windows SmartScreen может показать предупреждение о неизвестном издателе.
macOS остаётся на опубликованной версии 3.3.1.

## Изменения приложения

- Переработан интерфейс и доступность основных сценариев; добавлены настраиваемые
  индикаторы удержания взгляда (dwell).
- Улучшены сценарии сохранения и выхода из редактора, подтверждения действий и
  работа с медиа; пустой текст нельзя сохранить как текстовую картинку.
- Исправлен сценарий первой неверной попытки выбора в задании на соотнесение.
- Добавлена клавиатура для ввода взглядом в основном окне: компоновка C,
  предсказания для RU, ручной ввод EN и сохранение черновика.
- При сбое раннего обновления TTS-токена используется ещё не истёкший токен из кеша.
- Шрифты поставляются локально для работы без загрузки из сети.

Electron и electron-updater в этом диапазоне не обновлялись. Tobii обновлён до
опубликованного 0.2.17 с исправлением независимой joystick-активации и matching
corresponding source встроенного WASM. Vue обновлён совместимым patch до 3.5.44.

## Офлайн-предиктор RU

- Локальная CPU-модель T: до трёх однословных кириллических подсказок, без отправки
  текста в облако и без обучения на пользовательских переписках. EN вводится вручную.
- В замороженной AI-синтетической FINAL-симуляции (525 групп) экономия действий ввода
  составила 24,9%, 95% CI [23,8%; 26,0%]. Это не клиническое AAC-исследование.
- На записанном Windows CI: p95 266 мс, p99 268,4 мс, первый запрос 178 мс;
  private commit sidecar не превысил 7,7 МБ при принудительном лимите 512 MiB.
- Модельные веса, статистики, инструкции и соответствующие исходники доступны
  вместе с ресурсами `base-ru-v1`; исходные предложения и FINAL-данные не публикуются.

## Релизный контракт

- Версия приложения и обе корневые версии lockfile согласованы на 4.0.0.
- Preflight, inventory, имена установщиков, updater metadata, provenance и promotion
  согласованы на 4.0.0; promotion выбирает эти заметки вместо исторических notes 3.3.1.
- Локальные контрактные проверки отвергают старую версию, неверную архитектуру,
  отсутствующие или изменённые артефакты. Продвижение по-прежнему использует принятые
  байты без пересборки. Цель нового релиза — Windows x64 unsigned; macOS остаётся
  на неизменных compatibility assets 3.3.1.

## Исправления по результатам квалификации

- Копия набора не перезаписывает существующий файл и не меняет baseline оригинала.
  Предлагается свободное имя; поздняя коллизия безопасно отклоняется без перезаписи.
- Загрузки папок и наборов защищены от устаревших ответов и ABA-переходов;
  editor/explorer становятся доступны только после согласованной загрузки.
- Закрытие одного из перекрывающихся диалогов не снимает чужую блокировку взгляда.
- Поздние ответы калибровки после отмены не меняют UI нового запуска.
- Исправлены состояния ошибок картинок, озвучки, викторины и обновления;
  регистрационный код проверяется как шесть цифр.
- Замена gaze-цели с теми же координатами обновляет её DOM identity.
- Release preflight требует отдельный trusted approval модели и executable;
  наличие test sidecar не считается production approval.

## Ограничения квалификации

Проверки программные, CI-only. Физический Tobii, калибровка, слышимая речь и реальные
потребительские Windows 10/11 — **NOT TESTED**; владелец явно принял эти границы.
Измерения на CI не гарантируют ту же скорость на каждом 8-гигабайтном ПК.

Joystick-only regression с настоящим 0.2.17: 30/30 PASS. Production audit после
совместимого исправления Vue: 6 moderate, 0 high/critical; остаточные findings не
скрыты и допускаются только при совпадении reviewed lock/inventory/достижимости.
Публикация использует только принятые exact bytes после обязательных installer,
security и genuine-upgrade gates; эти заметки сами по себе не являются сертификатом.
Полный статус и условия допуска: [release-400-qualification.md](release-400-qualification.md).
