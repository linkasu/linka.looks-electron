# Issue145: сохранённые A/B/C и высокие системные кнопки

Локальная доработка в `/Volumes/data/linka/.opencode-worktrees/looks-145-options-5b1c2a54`.
Без commit/push, merge, релиза и установки поверх рабочей программы.

## Поведение

- Настройки → «Печать глазами: компоновка»: три обычные EyeButton-цели высотой 80 px.
  A — полная ширина, B — команды справа, C — подсказки слева.
- Выбор записывается в существующий electron-store, ключ `typingLayout`, и применяется
  при следующем открытии клавиатуры, включая перезапуск приложения. Отсутствующее или
  неизвестное значение даёт A. При ошибке записи прежний выбор остаётся активным,
  настройки показывают ошибку. Черновик `eyeTypingDraftV1` не изменяется этим выбором.
- Единственный writer нового ключа — mutation `typingLayout` в основном renderer;
  запись выполняется до изменения Vuex. Отдельное окно только читает нормализованное
  значение через существующий авторизованный `typing:sync/settings`. Нового IPC API нет.
  Конкурентного переключения внутри уже открытой клавиатуры нет: окно настроек скрыто.
- Старый бинарник игнорирует новый ключ; существующие данные и формат черновика не
  мигрируют. Возврат к старому бинарнику не требует удаления данных. Очередей, счётчиков,
  новых блокировок и фонового применения настройки нет.
- Управление, режимы и редактирование: минимум 80 CSS px по вертикали при высоте 600,
  96 px при высоте от 720; вместо прежних 52–56 px. Это размер кнопок, не сдвиг вверх.
  Навигация по тексту использует шесть крупных целей вместо временно скрытых букв;
  «Буквы» возвращает полный алфавит. Цифры и знаки остаются отдельными экранами.
- RU: 33 буквы, EN: 26, одновременно тремя рядами без листания. Три постоянные ячейки
  предиктора не меняют геометрию букв при загрузке/ошибке/появлении результатов.
  EN остаётся ручным вводом, без запросов к RU-модели.
- Общие EyeButton, PageWatcher, задержка dwell, индикация, пауза и возобновление не
  заменялись. URL-переключатель оставлен только для dev-сравнения; production использует
  сохранённый вариант и не показывает полосу прототипа.

## Изоляция и происхождение

Перед изменениями проверены процессы, cwd и git locks обоих worktrees, указанных
владельцем. Обнаружены MCP-процессы и оставшийся helper TobiiFree, но не выявлен writer
исходников. Git locks отсутствовали; неизвестные fences не снимались, процессы не
останавливались. Это ограниченная локальная проверка, не live-гарантия статуса сессий.

44 изменённых/новых файла выбранного дизайна скопированы в отдельный worktree от
`7976d0ba034b1b03ef8be6c3909780140b8ca29a`. SHA256 совпали до/после копирования.
Снимки обоих writers, патчи, их прежние артефакты и свидетельства проверки сохранены в
`/Volumes/data/linka/audits/issue145-options-5b1c2a54`.
Широкая унаследованная интеграция не является новой правкой этой задачи.
`options-only.patch` в этом каталоге описывает только изменения поверх снимка дизайна.
Зависимости переиспользованы через symlink, установки/пересборки dependencies не было.

## Ошибки прогонов и неразрешённые ограничения

- Первый browser-запуск остановился из-за занятого прежним сервером порта 5193.
  Чужой сервер не трогали, отдельный тестовый порт — 5196, reuse запрещён.
- Первая полная layout-матрица: 16 passed, 3 failed. В A на 1024×600, 1280×720,
  1366×768 обрезалась строка крупного шрифта. Исправлен line-height букв; повтор —
  19 passed. Первоначальные error-context сохранены в `layout-initial`.
- Общий quality gate **не зелёный**: `security-network.spec.ts` и
  `security-redirect.spec.ts` обнаруживают сохранение fixture Authorization при
  redirect. Предыдущие writers описали те же baseline failures; новый чистый baseline
  в этой задаче не запускался. Тесты/защита не ослаблялись, исправление этих ошибок
  не включалось в задачу клавиатуры.
- В sidecar Electron-прогоне есть `button.wav net::ERR_ABORTED` при закрытии окон;
  тест завершился успешно. Это built-file, **не packaged qualification**.
- Реальная production RU-модель, её latency, живое произношение (TTS замокан), Windows,
  аппаратная калибровка, масштаб ОС и целевое устройство владельца не квалифицированы.
  Tiny-модель и sidecar скопированы с проверкой SHA256 из исходного design worktree.
- Унаследованные packaged dependency blockers (conf/usb/semver) не исправлялись и не
  перепроверялись. Нужна отдельная квалификация до выпуска; доставка не закрывает issue145.

Повтор layout: `npx playwright test --config playwright.keyboard-prototype.config.ts`.
После `npm run build` повтор built-file Electron:
`npx playwright test --config playwright.typing.config.ts`.
Для аппаратного подтверждения нужна отдельная проба владельца на реальном экране
с его масштабом, расстоянием и калибровкой. Автозапуск, разрешения и Electron security
не менялись этой доработкой.
