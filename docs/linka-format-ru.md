# Формат файла `.linka`

Файлы с расширением `.linka` представляют собой обычный ZIP‑архив. Они используются приложением *Linka Looks* для хранения наборов карточек.

## Содержимое архива

- **config.json** – основной файл конфигурации набора. В нём описаны параметры сетки и перечень карточек.
- Изображения и звуковые файлы, на которые ссылаются карточки. Названия файлов совпадают с путями, указанными в `config.json`.

## Структура `config.json`

```json
{
  "version": "3.0",
  "withoutSpace": false,
  "directSet": false,
  "quizAutoNext": true,
  "quizReadQuestion": false,
  "pages": [
    {
      "id": "page-uuid",
      "mode": "standard",
      "columns": 3,
      "rows": 3,
      "cards": [
        {
          "id": "card-uuid",
          "cardType": 0,
          "width": 2,
          "imagePath": "...png",
          "title": "текст",
          "audioPath": "...mp3",
          "audioText": "текст",
          "audioVoice": "alena"
        }
      ]
    }
  ],
  "description": "описание"
}
```

- **version** – версия формата.
- **withoutSpace** – отображать ли пробел между карточками.
- **directSet** – открывать ли набор напрямую в окне общения.
- **quizAutoNext** – переходить ли автоматически к следующему вопросу.
- **quizReadQuestion** – озвучивать ли вопрос.
- **pages** – список страниц набора.
- **description** – произвольное описание набора.

Каждая страница содержит:

- **mode** – режим страницы: `standard`, `quiz`, `match`.
- **columns** и **rows** – размер сетки именно этой страницы.
- **topColumns** и **bottomColumns** – необязательные независимые размеры верхней и нижней строк страниц `match`; если их нет, `columns` используется для обеих строк.
- **question** – вопрос страницы викторины.
- **cards** – список карточек страницы.

Карточка может дополнительно содержать:

- **width** и **height** – размер карточки в ячейках сетки. Поля необязательны, по умолчанию равны `1`. Значения больше `1` работают на страницах `standard` и `quiz`; в `match` карточки всегда занимают одну ячейку.
- **answer** – пометка правильного ответа для страниц `quiz`.
- **matchId** – идентификатор группы связей для страниц `match`; все верхние и нижние карточки с одним ID образуют связи.
- **matchLane** – строка карточки (`top` или `bottom`) на страницах `match`.

Если карточка занимает несколько ячеек, следующие покрытые позиции в массиве `cards` рекомендуется заполнять пустыми карточками (`cardType: 2`) для корректной деградации в старых версиях приложения. Старые версии могут игнорировать `width`/`height` и показывать такие карточки как обычные `1×1`.

Формат `2.0` со старым плоским массивом `cards` по-прежнему читается приложением и автоматически мигрируется в `pages`.
