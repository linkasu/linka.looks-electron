# Issue145: четыре ряда высоких целей

Follow-up к локальному результату `looks-145-options-5b1c2a54`, не новая интеграция.

На основном экране остались строка черновика и четыре ряда целей вместо отдельных
рядов команд, подсказок, режимов, букв и редактирования. Три ряда букв видны целиком.
Команды и редактирование делят нижний ряд; B переносит команды вправо, а режимы вниз.
A теперь называется «буквы слева»: обещание полной ширины больше не соответствует
геометрии. Ключи сохранённого выбора A/B/C не изменились.

Краткие обозначения сохраняют прежние доступные имена: `Ⅱ` — пауза, `▦` — к наборам,
`▶/■` — озвучить/остановить, `↶` — Undo, `×` — очистить всё, `АБВ/ABC` — буквы,
`RU/EN` — сменить язык, `123` — цифры, `#+=` — знаки, `↔` — курсор,
`⇧/а` — регистр, `␣` — пробел, `⌫` — убрать символ, `⌫W` — убрать слово.
В навигации `W` означает слово, одинарная стрелка — символ, вертикальная черта — край.
Compact-режим общей кнопки паузы включён только в клавиатуре; прочие экраны не меняются.

Измеренные `getBoundingClientRect()` высоты в CSS px, одинаковые для RU/EN:

| Viewport | Вариант | Системные до → после | Буквы до → после |
| -------- | ------- | -------------------- | ---------------- |
| 1024×600 | A       | 80 → 129             | 60 → 129         |
| 1024×600 | B       | 80–112 → 129–196,5   | 88,66 → 129      |
| 1024×600 | C       | 80 → 129             | 86 → 129         |
| 1366×768 | A       | 96 → 166             | 90,66 → 166      |
| 1366×768 | B       | 96–145,59 → 166–252  | 124,66 → 166     |
| 1366×768 | C       | 96 → 166             | 119,33 → 166     |

Компромисс: минимальная ширина RU-буквы теперь 50,33 px на 1024×600 и 69,33 px
на 1366×768, EN — 67,22 и 91,92 px. Это не подтверждение удобства взгляда:
нужна проба на физическом трекере и целевом экране. CSS px не являются миллиметрами.
При ошибке сохранения отдельное предупреждение уменьшает высоту обычных целей
на 1024×600 до 118,5 px; оно не перекрывает кнопки и не скрывает несохранённый текст.

Матрица поведения не менялась: RU/EN, letters/numbers/symbols/cursor, uppercase,
три ячейки predictor, Undo, черновик и сохранённый A/B/C остаются прежними.
При паузе обычные цели выключены, resume остаётся доступен. Нет новых writers,
очередей, счётчиков, блокировок, IPC или миграций; формат хранилища и совместимость
старого бинарника не меняются. Автоматический/ручной ввод используют прежние обработчики.

Повтор browser-проверок: `npx playwright test --config playwright.keyboard-prototype.config.ts`.
Опциональный `TYPING_BASELINE_JSON` включает сравнение с реальными прежними bbox.
После `npm run build`: `npx playwright test --config playwright.typing.config.ts`.
Browser-матрица охватывает шесть viewport, A/B/C и RU/EN; проверяет алфавиты,
обрезку текста, выход за экран, перекрытия, рост bbox, неизменность геометрии predictor,
режимы, pause/resume, Undo, речь и ошибки загрузки/сохранения.
