# LINKa.смотри 4.0.2

**Тестовый prerelease, не стабильный выпуск.** Стабильной остаётся 3.2.13.
Публикация не меняет Latest и установщик на публичном зеркале.

## Симметрия стрелок перелистывания

- В просмотре набора обе стрелки имеют одинаковые размеры и вертикальное положение.
- Если кнопка «К наборам» занимает верх левой колонки, такая же область справа
  остаётся пустой и неинтерактивной. Стрелки расположены ниже на одной высоте.
- Если боковой кнопки выхода нет, стрелки занимают полную высоту. При скрытом
  перелистывании, одной странице или викторине лишняя правая колонка не появляется.
- Кнопка выхода и сетка карточек сохраняют прежнее расположение. Способы управления,
  пауза и блокировка взаимодействия не меняются.

Исправление загрузки ZIP из 4.0.1 сохранено. Клавиатура «Печать глазами», модель RU,
формат наборов, настройки и алгоритм Tobii не менялись. Выравнивание кнопок не
объявляется исправлением аппаратной фиксации взгляда.

## Совместимость и ограничения

Windows x64, установщик без цифровой подписи; SmartScreen может предупредить об
неизвестном издателе. macOS остаётся на неизменных compatibility assets 3.3.1.
Публикуются только квалифицированные exact bytes, без пересборки при публикации.

Проверки программные, CI-only. Физический Tobii, калибровка, слышимая речь и реальные
потребительские Windows 10/11 остаются NOT_TESTED без отдельной проверки устройством.
