# LINKa.смотри 4.1.0

## Строка вывода сверху или снизу

- В настройках можно выбрать положение строки вывода: сверху или снизу.
- Настройка общая для всего приложения: действует во всех наборах и в режиме
  «Печать глазами», сохраняется после перезапуска.
- По умолчанию строка остаётся сверху. Формат файлов наборов не меняется,
  пересохранять наборы не нужно.

Исправления 4.0.3 сохранены. Модель RU и алгоритм Tobii не менялись.

## Совместимость и ограничения

Windows x64, установщик без цифровой подписи; SmartScreen может предупредить об
неизвестном издателе. macOS остаётся на неизменных compatibility assets 3.3.1:
это не macOS 4.1.0, новой настройки в этих сборках нет.
Публикуются только квалифицированные exact bytes, без пересборки при публикации.

Проверки программные, CI-only. Физический Tobii, калибровка, слышимая речь и реальные
потребительские Windows 10/11 остаются NOT_TESTED без отдельной проверки устройством.
