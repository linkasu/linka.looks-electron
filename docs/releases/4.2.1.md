# LINKa.смотри 4.2.1

## Bubble в обычном канале Windows

- Функция Bubble из тестовой версии 4.2.0 включена в обычный релиз Windows x64.
  Раздел настроек — «Взаимодействие с системой»: показать точку взгляда, размер,
  яркость и плавность. На чистом профиле показ выключен.
- Оверлей и трей — Electron; C# используется только для получения данных Tobii.
  Дополнительная установка Bubble не требуется.
- Bubble продолжает работать после сворачивания и полного выхода из «Смотри».
  Завершить текущий сеанс можно через трей; сохранённый выбор не меняется.
- Трей и настройки используют единый выбор, пауза управления карточками не
  останавливает Bubble. При потере свежих данных точка скрывается.
- Оверлей не выполняет клики, не двигает системный курсор и не записывает историю
  координат. При работающем standalone Bubble второй оверлей не создаётся.

Это version-only выпуск: алгоритм Bubble, SDK, зависимости и формат пользовательских
данных относительно 4.2.0 не изменены. Ранее опубликованная 4.2.0 остаётся prerelease.

## Проверки и ограничения

13 ноября 2026 года владелец проекта сообщил о выполненной ручной проверке Bubble
на Windows-стенде. Конфигурация этой проверки не зафиксирована как полный прогон
обеих моделей Tobii Eye Tracker 4C и 5, поэтому такой прогон не заявляется.
Программная квалификация CI не заменяет аппаратные проверки из
`docs/bubble-release-checklist.md`.

Отслеживается только основной монитор. Точка показывает приблизительную область
внимания и не подтверждает чтение или понимание текста. Нет управления мышью,
клавиатурой, автозапуска при входе в Windows и поддержки UAC/экрана блокировки/
exclusive fullscreen. Настройки предназначены для сопровождающего.

## Установка и обновление

Windows 10/11 x64. Установщик приложения не подписан; SmartScreen может предупредить
о неизвестном издателе. .NET Framework 4.8 и VC++ 2012 x64 входят в установку и
устанавливаются при необходимости; Windows может потребовать перезагрузку.
Перед обновлением рекомендуется сохранить резервную копию рабочих наборов.

Windows-установщик публикуется только после обязательных software/security/packaged/
genuine-upgrade гейтов, с продвижением тех же квалифицированных байтов без пересборки.
Этот выпуск становится Latest и обновляет публичный стабильный канал.
macOS — неизменные compatibility assets 3.3.1, **без Bubble**, а не macOS 4.2.1.

Право распространения Tobii Interaction SDK 0.7.3, включая x64 DLL, подтверждено
владельцем проекта; notices и закреплённые зависимости сохраняются.
