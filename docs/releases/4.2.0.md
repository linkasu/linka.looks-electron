# LINKa.смотри 4.2.0

<!-- release-channel: prerelease -->

## Тестовая версия Bubble для Windows x64

- В настройках появился раздел «Взаимодействие с системой»: показ приблизительной
  точки взгляда, размер, яркость и плавность. По умолчанию показ выключен.
- Оверлей и трей реализованы на Electron; C# используется только для получения данных
  Tobii. Дополнительная установка Bubble не требуется.
- Bubble работает независимо от основного интерфейса «Смотри»: сворачивание и полный
  выход не завершают его. Завершить текущий сеанс можно через значок Bubble в трее.
- Трей и настройки используют один сохранённый выбор. Пауза управления карточками не
  останавливает Bubble. При отсутствии свежих данных точка скрывается.
- Оверлей не нажимает элементы, не перемещает системный курсор и не записывает историю
  координат. При обнаружении работающего standalone Bubble второй оверлей не запускается.

## Что проверить тестеру

Windows 10/11 x64, Tobii Eye Tracker 4C и 5; основной монитор, масштабы 100/125/150/200%,
подключённый второй экран. Проверить сквозные клики, сохранение фокуса и обычную клавиатуру,
согласованность трея и настроек, полный выход из «Смотри», паузу, отключение и подключение
трекера, установку и обновление при работающем Bubble.

Протокол проверки: `docs/bubble-release-checklist.md`. До результатов тестера физический
Tobii, совместная работа двух SDK-клиентов и потребительские Windows 10/11 — **NOT_TESTED**.
Точка показывает приблизительную область внимания, а не чтение или понимание текста.

## Ограничения и установка

Это **GitHub prerelease**, не Latest и не обновление публичного стабильного канала.
Канал закреплён в этих release notes: автоматическая публикация также обязана сохранить
признак prerelease; программные, security и upgrade-гейты остаются обязательными.
Установщик Windows не подписан; SmartScreen может предупредить о неизвестном издателе.
В установку включены .NET Framework 4.8 и VC++ 2012 x64 с проверенными исходными файлами;
при необходимости установка может потребовать перезагрузку Windows.

Отслеживается только основной монитор. Нет управления мышью, клавиатурой, автозапуска при
входе в Windows и поддержки UAC/экрана блокировки/exclusive fullscreen.
macOS — неизменные compatibility assets 3.3.1, **без Bubble**, а не macOS 4.2.0.

Право распространения используемого Tobii Interaction SDK 0.7.3, включая x64 DLL,
подтверждено владельцем проекта при подготовке этой тестовой версии 10 ноября 2026 года.
Публикация по-прежнему требует штатной программной квалификации exact bytes;
подтверждение лицензии не заменяет проверку на оборудовании.
