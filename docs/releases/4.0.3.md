# LINKa.смотри 4.0.3

## Картинки из текста без автоматических переносов

- При создании картинки из текста шрифт уменьшается, чтобы фраза помещалась по
  ширине карточки, вместо переноса строк и разрыва слов.
- Явно введённые переносы строк сохраняются. Для короткого текста, который уже
  помещается, размер шрифта не меняется.
- Уже созданные картинки, остальные ресурсы карточек и формат наборов не меняются.
- Очень длинная строка может получить мелкий шрифт. Если текст не помещается даже
  при минимальном размере, приложение просит сократить текст, не обрезая его.

Исправления 4.0.2 сохранены. Клавиатура «Печать глазами», модель RU, настройки и
алгоритм Tobii не менялись. Исправление text2img не объявляется исправлением
аппаратной фиксации взгляда.

## Совместимость и ограничения

Windows x64, установщик без цифровой подписи; SmartScreen может предупредить об
неизвестном издателе. macOS остаётся на неизменных compatibility assets 3.3.1.
Публикуются только квалифицированные exact bytes, без пересборки при публикации.

Проверки программные, CI-only. Физический Tobii, калибровка, слышимая речь и реальные
потребительские Windows 10/11 остаются NOT_TESTED без отдельной проверки устройством.
