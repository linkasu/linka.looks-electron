# LINKa.смотри 4.0.1

**Тестовый prerelease для проверки, не стабильный выпуск.** Стабильной остаётся
3.2.13. Эта публикация не меняет Latest и установщик на публичном зеркале.

## Исправление загрузки наборов

- Устранена повторная распаковка всего ZIP при чтении конфигурации, превью,
  отдельной картинки или аудио. Главная больше не обрабатывает все медиа набора
  ради одной обложки — как после запуска, так и при возврате к наборам.
- Структура архива, пути и лимиты проверяются до чтения; запрошенный файл проходит
  проверку размера и CRC. Импорт, сохранение, объединение и распаковка по-прежнему
  проверяют весь архив. Повреждённое неиспользуемое медиа не мешает показать обложку,
  но отклоняется при чтении и не допускается в импорт/сохранение.

Модель RU, Tobii, настройки и формат пользовательских наборов не менялись.
Проблема фиксации правой стрелки Tobii этим выпуском не объявляется исправленной.

## Совместимость и ограничения

Windows x64, установщик без цифровой подписи; SmartScreen может предупредить об
неизвестном издателе. Обновление проверяется с опубликованного 4.0.0 без подмены
его installer или пользовательских данных. macOS остаётся на неизменных
compatibility assets 3.3.1.

Проверки программные, CI-only. Физический Tobii, калибровка, слышимая речь и реальные
потребительские Windows 10/11 — NOT_TESTED. Измерения скорости на CI или Mac не
являются гарантией времени загрузки на конкретном Windows-компьютере.
Публикуются только квалифицированные exact bytes; ошибки внешнего зеркала
отображаются отдельно от статуса GitHub release.
