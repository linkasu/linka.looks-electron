# Bubble: блокирующий checklist релиза Windows

Все пункты ниже **NOT TESTED / PENDING**, пока к конкретному кандидату не приложены
результаты и версии ОС, приложения, Tobii runtime и оборудования. Синтетический CI
не является проверкой оборудования или разрешением на распространение SDK.

## Сборка и состав

- [ ] `npm run bubble:backend:check`: синтетические Checks без подключения SDK/трекера.
- [ ] Windows x64: .NET SDK 10, `npm run electron:build -- --win --x64 -p never`.
      `preelectron:build` собирает `native/tobii-backend/TobiiBackend.csproj` (net48)
      в Release; на macOS/Linux backend не собирается и не упаковывается.
- [ ] В `resources/extraResources/bubble-backend/` присутствуют
      `Linka.TobiiBackend.exe`, `Tobii.EyeX.Client.dll`,
      `Tobii.Interaction.Model.dll`, `Tobii.Interaction.Net.dll` и сгенерированный
      `Linka.TobiiBackend.exe.config`, если он есть в output. Нативная DLL и EXE —
      PE x64, SDK DLL — managed. Нет PDB/XML или неизвестных runtime-зависимостей.
- [ ] `npm run test:packaged-resources` на распакованной Windows-сборке.
      Сборщик не исполняет SDK, не скачивает его самостоятельно и останавливается
      при неполном/неожиданном output; получение пакетов NuGet остаётся restore проекта.
- [ ] macOS/Linux не содержат `extraResources/bubble-backend`, даже после локальной
      Windows staging-сборки. Все прежние общие ресурсы Windows сохранены.

## Реальное оборудование и взаимодействие

- [ ] Отдельные прогоны Tobii Eye Tracker 4C и Tobii Eye Tracker 5: калибровка,
      подключение, отключение, повторное подключение, ошибки сервиса.
- [ ] Два трекера/параллельные tracker-провайдеры: отсутствие конфликтов владения,
      корректное переключение и остановка; указать фактически допустимые комбинации.
- [ ] Windows DPI **100%, 125%, 150%, 200%**: основной и второй монитор, второй
      монитор слева/сверху, разные масштабы; корректные экранные координаты.
- [ ] Click-through вне активной области, отсутствие кражи фокуса и перемещения
      системного курсора; проверка доступности клавиатурой и закрытия окна.
- [ ] При stale gaze **300 ms** активация прекращается; отключение трекера,
      зависание/завершение backend и возобновление не вызывают ложный клик.
- [ ] Standalone backend: mutex запрещает второй конфликтующий экземпляр;
      после штатного выхода и аварии возможен повторный запуск.

## Установка, обновление и право распространения

- [ ] Чистая поддерживаемая Windows: проверена установка **.NET Framework 4.8**
      и требуемого Tobii SDK native VC++ runtime x64; версии и официальный источник
      установщика зафиксированы. SDK 10 — средство сборки, не runtime net48.
- [ ] Отсутствующий runtime, отказ/отмена/ошибка установки, требование reboot:
      installer явно прекращает установку/обновление, не запускает неисправный Bubble.
- [ ] Обновление при запущенном Bubble: процесс корректно остановлен, файлы не
      заблокированы; отмена/ошибка обновления не оставляет смешанные runtime-файлы.
- [ ] Проверены обновление старой версии, повторная установка, uninstall и rollback;
      пользовательские данные и существующие tracker-настройки сохранены.
- [ ] Получено подтверждение прав на фактические Tobii DLL, версия/архив и условия
      лицензии зафиксированы; сохранены необходимые notices. **PENDING**:
      наличие SDK в NuGet/старом EyeLog и согласие на риск не означают разрешение Tobii.

Изменения установщика и проверка prerequisite/abort-сценариев ведутся отдельно;
этот checklist не утверждает, что они уже реализованы или проверены.
